Dental Radiograph Detection with Modified Backbone

Prior work, published and presented at the International Conference on Sustainable Information Engineering and Technology (SIET), utilized a YOLOv11 pipeline trained over 500 epochs to achieve 91% accuracy and a 10.3 ms inference time in dental radiograph analysis. Deep Learning WordPress Intrusion Detection

Engineered a deep learning pipeline by pairing a hybrid CNN-LSTM network with custom text processing, tokenizing over 88,000 log entries across a 20,000-vocabulary corpus to classify 8 WordPress attack types at 98.74% accuracy. Detailed confusion matrix evaluations revealed open-source dataset imbalances and trade-offs in model complexity. This insight proved that traditional machine learning provides a vastly more efficient, low-latency deployment strategy for production systems.

RAG LLM Implementation on Extracting PDF Context

Engineered an end-to-end Retrieval-Augmented Generation (RAG) system that integrates custom document chunking, dense vector embeddings, and similarity search with a large language model. The pipeline dynamically retrieves relevant domain context from a vector database to ground LLM responses, significantly reducing hallucination rates and enabling precise, context-aware question answering over custom datasets.
